Check Your Shift, Know Your Rights — 网站源文件

这是 2026年11月3日更新的简约版本，包含完整中英文题库、计分、情况检查和个性化帮助链接。

使用方法
1. 解压 ZIP 后，双击 index.html 可以在浏览器中打开。
2. 上传至 GitHub Pages 时，将 index.html、style.css、data.js 和 app.js 一起放在仓库根目录。
3. GitHub 仓库 Settings → Pages → Deploy from a branch，选择 main 和 / (root)，保存后等待生成网址。

文件说明
index.html：页面结构
style.css：页面样式
app.js：中英文切换、答题、计分及结果页面
data.js：题库、解释及官方资料链接

不需要安装依赖，也不需要编译。修改时请保持上述四个文件位于同一目录。
用户的答题进度保存在各自浏览器内，不包含在本压缩包中。
